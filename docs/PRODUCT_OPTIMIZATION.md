## 进度更新协议

完成任何已授权项后，作者必须：

1. 把本文件对应周次改成 `[x]`，写下提交 SHA、测试结果、遗留问题。
2. 把「当前项」改成下一周，且只保留一个当前项。
3. 同步修改 `docs/COMMERCIALIZATION_STATUS.md` 的 Next Authorized Step。
4. 未通过 `npm test` 和 `npm run build` 不得勾选完成。
5. 不得跳周，不得顺便做 P2/P3、支付、云同步。
6. 不得把「催收备忘」做成工单系统，不得做应付/报税直连。

## 原则

1. 只加深四件事：流水、应收、月结、备份。
2. 免费工具保持匿名、免登录、永久免费。
3. 演示模式改动不写入真实公司。
4. 可以继续从 `pro/app.js` 抽出可测试模块，但不要整文件重写。
5. 第 3 个月结束前不上支付、不开云同步。

## 这 3 个月明确不做

- 支付、订阅、自动扣费
- 云同步、多设备实时账
- P2 试用倒计时（可设计，不可上线）
- 应付 / 进项发票
- 微信支付宝自动对账
- 税务申报直连
- 工资模块并入工作台
- 催收工单 / 短信 / 多人协作
- 整份重写 `pro/app.js`
