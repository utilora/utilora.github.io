# A 股 AI 智能选股平台 MVP 开发计划

> 本计划从“新建独立仓库”开始。当前工作区属于其他产品，未确认仓库归属前不得开始实现。

## 1. MVP 范围

### 必须交付

- 中文桌面优先界面，含首页、每日规则排行榜、股票详情/K 线、技术指标、基础回测、数据更新状态。
- 演示数据模式；股票代码/名称/拼音搜索。
- 交易日历、股票主数据、日 K、复权因子/口径、停牌/可交易状态和更新记录。
- MA、MACD、RSI、量价、波动率、趋势强度等版本化指标。
- 可解释规则评分、每日快照、历史排名和每项得分原因。
- 基础但真实的 A 股日频回测：T+1、停牌、涨跌停、成本、基准。
- 数据来源、有效时间、更新时间、质量状态和结果追溯。
- Docker/Codespaces/CI，以及开发/测试环境隔离。

### 只设计或预留

- LightGBM 1/3/5 日模型、校准、版本和预测表；不训练、不展示概率。
- 注册登录、自选股、会员 entitlement 与管理后台骨架。
- 商业数据 Provider 接口。

### 不做

- 支付、自动交易、券商连接、个性化建议、目标价、收益承诺。
- LLM 直接生成交易结论。
- 未授权真实数据公开部署。

## 2. 建议开发顺序

### Sprint 0：仓库与决策基线（2–3 人日）

- 新建独立私有 GitHub 仓库和受保护 `main`；开发分支 `codex/mvp-foundation`。
- 落地 monorepo 目录、ADR、许可证/第三方清单、CODEOWNERS、PR 模板。
- 建立 devcontainer、Compose、`.env.example` 和最小 CI。
- 确认演示数据许可与合成数据生成规范。

验收：Codespaces 与本地一条命令启动空 Web/API/DB/Redis；CI 通过；无真实 secret。

### Sprint 1：领域模型与数据中心（5–8 人日）

- Alembic 首批表：data source/snapshot、instrument、calendar、bar、status、update job、quality issue。
- `MarketDataProvider` 契约和 demo provider。
- 幂等采集、标准化、质量规则、任务状态 API。
- 固定小数据集覆盖正常、缺失、重复、停牌和异常 OHLC。

验收：重复导入不重复；阻断异常不会发布；每条 K 线可追溯来源和快照。

### Sprint 2：指标与查询 API（4–6 人日）

- 指标定义/因子集/因子值迁移与注册表。
- MA、EMA、MACD、RSI、成交量变化、波动率和趋势强度。
- 股票搜索、K 线、指标 API；数值 golden tests。
- Redis 缓存及快照驱动失效。

验收：无未来数据读取；增量和全量结果在容差内一致；不足窗口明确为 missing。

### Sprint 3：规则选股（4–6 人日）

- 受限 JSON DSL、策略版本、股票池快照、筛选运行与结果表。
- 可解释子分、硬过滤和排名；每日调度与幂等发布。
- 历史筛选查询与追溯 API。

验收：同版本/快照结果确定；停牌等硬过滤可解释；UI/API 无概率和荐股措辞。

### Sprint 4：回测引擎（7–10 人日）

- 事件对象、订单/成交/持仓/现金账本和基准。
- T+1、停牌、涨跌停、费用版本、滑点、公司行动最小支持。
- 异步任务、净值/成交/不可成交 API、指标计算。
- 固定场景测试和手工账本对照。

验收：现金与持仓守恒；成本可逐笔核对；未来价不可用于当日成交；结果可复现。

### Sprint 5：六个 MVP 页面（6–9 人日）

- Ant Design token 与金融终端布局；中文文案和风险提示。
- 首页状态卡、排行榜表格、股票搜索/详情、ECharts K 线/指标、回测页、数据状态页。
- loading/empty/error/stale/demo 状态；桌面与手机关键路径。

验收：六页可用；来源/时间/质量在对应页面可见；键盘与颜色辅助信息基本合格。

### Sprint 6：安全、可靠性和交付（4–6 人日）

- 鉴权模式门禁、限流、审计、CORS/CSRF、安全头。
- 备份/恢复演练、任务失败重试、日志与健康检查。
- E2E 主路径、迁移测试、依赖审计、镜像扫描、README。
- 内部测试环境发布（需用户明确批准并确认无额外付费）。

验收：CI 全绿；恢复演练记录；高危依赖为零或有批准例外；未公开生产部署。

总估算：单名熟练全栈/量化工程师约 6–9 周；2–3 人并行约 4–6 周。数据授权、合规和真实回测验证不包含在纯开发估算内，且可能决定公开发布日期。

## 3. 页面功能清单

### 首页仪表盘

- 最近成功交易日与更新时间。
- 数据/指标/筛选任务状态和告警。
- 最新规则候选 Top 10、子分摘要与“研究用途”提示。
- 市场概览仅在数据覆盖和许可明确后启用。

### 每日选股排行榜

- 策略、日期、交易所/板块过滤；排名、规则分、命中原因、质量标记。
- 策略版本和历史日期切换；导出在许可允许后启用。
- 不展示买卖建议、目标价、模型概率。

### 股票详情与 K 线

- 代码/名称/拼音搜索；主数据与上市状态。
- 日 K、成交量、复权口径、时间范围；停牌/缺失显式标识。
- 数据来源、as-of、抓取时间和快照追溯。

### 技术指标分析

- MA、MACD、RSI、量能、波动率、趋势强度。
- 指标定义、窗口、版本和不足窗口状态。
- 规则命中证据，不输出 AI 结论。

### 历史回测

- 选择已发布策略、日期、基准、Top-N 和调仓频率（受限参数）。
- 异步进度、净值/回撤/基准图、关键指标、成交与不可成交明细。
- 成本和 A 股规则说明、版本追溯、结果局限。

### 数据更新状态

- 数据源能力与健康状态、最近任务、行数和耗时。
- 缺失/异常/阻断数量、最后成功时间、stale 提示。
- 管理员可重试；普通用户只读。

## 4. 测试策略

- 单元：指标数值、规则评分、费用、T+1、涨跌停、指标统计。
- 属性/不变量：OHLC 合法、现金持仓守恒、未来数据不进入特征、重跑幂等。
- 集成：PostgreSQL 约束/迁移、Redis 缓存、任务发布原子性。
- 契约：OpenAPI 与 TS 客户端、错误格式、权限和概率字段门禁。
- E2E：搜索→K 线；排行榜→详情；创建回测→查看报告；数据失败→stale 展示。
- 回归：固定 demo 快照的排行榜哈希和回测 golden result。

每个 PR 运行受影响测试、lint、类型检查；合并前运行完整 CI。外部数据网络测试与确定性单测分离。

## 5. Definition of Done

- 需求与验收测试通过；无静默数据错误。
- 结果带来源、as-of、版本与追溯 ID。
- 数据库迁移和回滚/恢复策略已审查。
- 新依赖完成许可证与漏洞检查，锁文件更新。
- 文档、环境变量模板和风险提示同步。
- 没有 secret、真实用户数据或未经授权行情进入仓库/CI artifact。
- 未启用模型概率、支付、券商或公开生产服务。

## 6. 下一阶段第一批可执行任务

仅在用户确认独立仓库位置后执行：

1. 建立新仓库骨架、分支保护建议和 ADR-001。
2. 创建 `apps/web`、`apps/api` 的最小健康页，不含业务实现。
3. 创建 devcontainer 与 Compose（PostgreSQL/Redis/API/Web）。
4. 建立 Alembic 和首批市场数据表。
5. 定义 `MarketDataProvider` Protocol 与纯合成 demo provider。
6. 配置 CI：Python/TS lint、类型、单测、迁移检查、secret/dependency scan。
7. 编写第一组数据质量与幂等集成测试。

## 7. 决策/审批门

- 开始编码前：确认新仓库、所有者、可见性、许可证和 demo 数据方案。
- 接真实源前：逐源批准授权矩阵，不以 AKShare 可访问性代替授权。
- 训练模型前：批准标签、股票池、切分和指标协议。
- 部署测试环境前：批准云厂商、区域、预算和 secret 管理。
- 公开上线前：完成证券业务、数据许可、隐私、安全和宣传文案合规审查。
